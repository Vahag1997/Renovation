# База данных (Supabase) — портфолио

Простая инструкция. Делается один раз, ~10 минут. Программировать не нужно.

## Шаг 1. Создать бесплатный проект Supabase
1. Зайди на https://supabase.com → **Start your project** → войди через Google/GitHub.
2. Нажми **New project**.
3. Имя: `studio-aura`. Придумай пароль базы (запиши его). Регион — ближайший (Frankfurt).
4. Подожди 1–2 минуты, пока проект создастся.

## Шаг 2. Создать таблицы
1. Слева открой **SQL Editor** → **New query**.
2. Открой файл `supabase/schema.sql`, скопируй **всё** и вставь в окно.
3. Нажми **Run**. Должно написать «Success».

## Шаг 3. Добавить примеры портфолио
1. Снова **New query**.
2. Скопируй всё из `supabase/seed.sql`, вставь и нажми **Run**.
3. Слева открой **Table Editor** — увидишь таблицы `categories` и `projects` с примерами.
   Это и есть твоя админка: здесь добавляешь проекты, тексты и картинки.

## Шаг 4. Дать мне ключи (чтобы сайт читал базу)
В Supabase открой **Project Settings → API** и пришли мне:
- **Project URL** (вид `https://xxxx.supabase.co`)
- **anon public** ключ (длинная строка)

> Эти два значения публичные и безопасные (с ними можно только **читать** контент).
> Я добавлю их в файл `.env.local` (он не попадёт в Git) и подключу сайт к базе.

## Что дальше
После шага 4 я переключу страницы портфолио на чтение из базы.
Дальше ты сможешь сам в **Table Editor** добавлять проекты, а на вкладке
**Storage** загружать свои фотографии.
